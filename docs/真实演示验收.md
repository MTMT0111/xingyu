# 2026-10-21 真实微信后台演示

本轮主线是后台读取视频内容与评论。实际测试使用本机已登录的电脑版微信视频号；未用录屏、截图封面或合成环境代替。测试只生成草稿，没有给任何微信联系人发送消息。

## 两次实际运行

| 入口 | 取得的真实资料 | 模型结果 |
| --- | --- | --- |
| 后台搜索标题，核对“小莉帮忙”发布的保暖话题视频后按视频 ID 分析 | 38.313 秒；6 帧；174 字语音转写；78 条评论与回复样本 | deepseek-flash 返回摘要、可能的分享意图和回复 |
| 之前从微信取得的同一条 feed 分享链接 | 38.313 秒；6 帧；177 字语音转写；77 条评论与回复样本 | deepseek-flash 返回有效回复 |

评论数量取决于实际返回的分页样本和时点，不能称为全部评论。语音为本机 Whisper 自动转写，可能有识别误差；画面只抽取六帧。模型未被微调，本轮改的是资料链路和生成提示词。

原始签名链接、视频 ID、解密参数、评论全文和完整模型结果只保存在忽略提交的 `work/`。`scripts/channels-live-smoke.mjs` 仅在实际取得视频、音画证据和 LLM 回复后输出成功记录；单元测试和浏览器测试仍使用明确标注的替身。

## 演示步骤

1. 保持本机微信登录，打开视频号首页。连接器需要这个会话，不需要播放目标视频。
2. 启动已配置的 Node 服务与 Windows 助手。点悬浮球或按 **Ctrl+Alt+R**。
3. 点“搜索视频号”，输入分享卡片中的关键词；核对作者与标题，选择原视频。相似结果不能自动当成同一个视频。
4. 在“回复对象”填写称呼；“关系与习惯”写自己确认的背景，例如“妈妈，关系亲近，简短自然”。这些是本机备注，不是读取到的微信好友列表。
5. 点“生成回复”。后台读取视频文件、语音、评论，再生成。点“查看依据”核对实际资料；编辑后“复制 · 回到微信”，在正确对话里粘贴确认发送。

也可粘贴实际文章链接，后台提取公众号正文；无法访问或需要验证时明确报错，不凭标题编写文章摘要。

## 成熟产品借鉴

- [PopClip](https://www.popclip.app/extensions/)：内容附近的少量操作，二级功能不挤满主界面。
- [Raycast Quick AI](https://manual.raycast.com/ai/quick-ai)：按需唤起小窗、生成后回到原应用、扩展分析按需展开。
- [wx_channel](https://github.com/nobiyou/wx_channel/blob/main/docs/API_README.md)：真实微信会话中的搜索、详情与评论 API；固定源码与兼容补丁在 `integrations/wx-channel/`，保留 MIT 许可。

仅借鉴交互模式，不复制这些产品的品牌或界面资产。微信后台读取由第三方连接器实现，不是微信官方授予的通用聊天读取接口。
