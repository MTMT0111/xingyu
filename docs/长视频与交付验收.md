## 真实微信与真实模型

在已有授权的本机连接器与已登录微信会话下，后台搜索得到刘震云演讲剪辑，读取源视频及评论，没有打开/播放目标视频，不依赖屏幕截图。调用真实 DeepSeek Flash 完成三段视觉与音轨合并分析，最终返回可编辑回复。

| 项目 | 实测 |
| --- | --- |
| 视频长度 | 376.605 秒 |
| 音轨分段 | 0–180、180–360、360–376.605 秒 |
| 分段转写 | 594 / 668 / 78 字，共 1342 字 |
| 抽帧 | 18 帧（画面为采样，不能称逐帧看完） |
| 评论与回复 | 60 条，本样本最高 25 赞 |
| 耗时 | 66.345 秒，仅本机此次测量 |
| 模型 | deepseek-flash，非模板 |

原始模型回复：

> 刘震云讲郓哥那两句话牵出几条人命，这个例子挺抓人的。一句话的分量有时候真比一堆道理重，不过那句让人动心的话，估计谁也说不准。

另外一条真实短视频的评论接口返回了 444、79 赞等计数；已核对上游字段 `likeCount`。结果保留评论原文、已返回的回复关系、实际点赞数；缺少计数用未知表示。原文主导判断，评论补充视角，点赞不是事实正确率。

原始带会话标识的结果只在被 Git 忽略的本机 `work/` 中保存；提交和公开展示只用脱敏指标、概述和模型回复，不公开签名 URL、微信身份、密钥或评论者昵称。

## 实现与回归

- 桌面和后台下载改为流式写入磁盘；512 MiB 容量，上传票据一次性消费并过期清理，取消/失败也清理。
- 全部音轨每 180 秒处理一段，每段六帧；分段末尾连续性校验，全部分段参与逐层摘要；不会截掉结尾再声称读完。
- Windows 拖入接受文件、普通文本中的链接、HTML 链接、Unicode URL 流；真实链接优先于卡片标题。仅含标题的拖入明确拒绝；普通消息使用粘贴入口。未知微信私有格式不假装支持。
- 关系备注多行展示；更换对象时切换相应已保存备注，新对象不沿用上一个对象的备注。
- 工程回归 80/80；浏览器 56/56，包含拖入链接、评论安全渲染、长视频最后分段可见。浏览器接口夹具已标注，不能替代上方真实微信结果。
- Windows 编译、自检通过。公开展示页在 1280 / 390 / 320 像素下验证编辑、复制或手动选中、恢复、无横向溢出与下载入口；无 JS 异常。
