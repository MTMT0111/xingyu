# 微信后台内容读取

更新：2026-10-21。**真实后台搜索和真实分享链接都已通过端到端测试**，详见 [真实演示验收](真实演示验收.md)。本轮不再以实时录屏作为视频理解入口。

## 处理方式

- 视频号搜索：`GET /api/channels/search?q=关键词` 经本机已登录微信会话搜索，返回作者、标题、时长与候选标识。用户选定后 `/api/reply` 的 `channel` 传入 `object_id`、`nonce_id`。不能用相似结果冒充原视频。
- 微信卡片拖入失败时：桌面“选取微信视频”/`Ctrl+Alt+V` 让用户框住一张卡片，本机 OCR 提取标题/作者，自动搜索；候选仍由本人核对。卡片图片不上传，不用于生成内容总结。这是卡片定位的替代入口，不是微信私有拖拽协议接入。
- 分享链接：自动识别 `weixin.qq.com/sph/...`、feed 页、finder-preview。真实 feed 链接已通过测试；其 64 位参数在本机精确解码，避免上游缺失的解码函数。短分享链接依赖上游会话支持，未对所有格式逐一真机验收。
- 后台取得真实视频文件，选择微信实际提供的较小 H.264 规格；文件上限 512 MiB，每 180 秒一段处理完整音轨并采样画面。已实测 376.605 秒视频，18 帧、1342 字转写，详见[长视频验收](长视频与交付验收.md)。受可下载权限、文件大小、90 分钟处理期限限制，不能保证任意长度或任意视频。
- 评论读取最多两页一级评论、前三个回复分支、合计最多 80 条；去除账号、头像等字段，保留评论正文和回复关系。只称为样本；读取失败如实标记，不编造。
- 公众号：提取 `mp.weixin.qq.com` 公开正文。验证码、删除、不可访问时停止，不能仅靠标题总结。
- 普通消息：直接结合用户提供的关系和表达习惯生成自然回复。

## 本机环境

连接器固定源为 [nobiyou/wx_channel](https://github.com/nobiyou/wx_channel)，基线与 MIT 许可在 [补丁目录](../integrations/wx-channel/README.md)。本地补丁修复了令牌未注入、无关站点 API 被误拦截、响应头和 API 监听地址；Go 包测试、编译与实际会话连接通过。

用户已批准安装并亲自确认 SunnyRoot。实际证书位于当前用户 Root，指纹 `D70CD039051F77C30673B8209FC15EFA650ED52C`。连接器使用微信进程代理；原有系统代理未改。新设备需由所有者同意安装，微信版本变更可能影响兼容性。

`.env` 使用 `CHANNELS_BRIDGE_URL=http://127.0.0.1:2026`，`CHANNELS_BRIDGE_TOKEN` 与连接器 `secret_token` 一致，保留现有 `LLM_*`、`MEDIA_PYTHON`、`WHISPER_MODEL_PATH`。密钥、签名 URL、媒体解码参数不传给模型、不提交 Git。

此功能仅用于本机服务，不通过公网邀请页面暴露私人微信会话。安卓 Debug 可以 `adb reverse tcp:4173 tcp:4173` 经 USB 调用同一后端；这仍依赖电脑微信，不是手机独立后台读取。

## 真实测试命令

`node --env-file-if-exists=.env scripts/channels-live-smoke.mjs <本机链接文本文件>`

或者 `node --env-file-if-exists=.env scripts/channels-live-smoke.mjs --search <关键词> <已核对的视频ID>`。

脚本经真实接口搜索/下载、转写并调用模型，只有全部成功才保存忽略提交的 `work/channels-real-result.json`。本轮已验证一条 38.313 秒真实视频；不能推广为所有视频都支持。

模型仍为已配置的 DeepSeek，未做微调。生成提示词要求贴合具体内容、少套话，区分发布者陈述与评论观点，不捏造用户经历或声称本人看过。77 项工程测试与 55 项浏览器回归为契约/界面验证，不能替代上述实际运行。
