项目统一在 **[MTMT0111/xingyu](https://github.com/MTMT0111/xingyu)**，产品名称是“知意”。保留历史仓库名是为了继续使用已有代码历史和共创者权限。

| 内容 | 唯一维护位置 | 使用入口 |
| --- | --- | --- |
| 完整源码与开发文档 | 本仓库 main | 仓库首页 README |
| 稳定展示页、文字示例 | 本仓库 site/ | https://mtmt0111.github.io/xingyu/ |

## 发布

1. 修改客户端/后端后执行 `npm test`；涉及 Windows 客户端时执行 `./clients/windows/build.ps1`。
2. 修改展示页只改 site/；推送到 main 后由 Publish demo 工作流部署。站点需要先在 Settings → Pages 启用 GitHub Actions。
3. 执行 `./scripts/package-windows.ps1`。安装包按白名单生成在忽略目录 work/distribution-日期时间/，核对内容和 SHA256SUMS.txt 后上传**本仓库** Release。
4. 发布说明写明源码提交、实际测试、安装步骤和未完成项。运行包不是源码 ZIP，不包含开发者本机配置。

旧 haohaohui-demo 已归档，不再接收功能开发；首页、showcase.html、text-demo.html 均跳转到新站，旧网址仅作为迁移入口保留。历史测试报告中的旧网址是当时的验收对象，不能改写成新站已经通过的证据。
