# 本地部署与安卓演示

目标是 **电脑本地服务 → 安卓 USB 真机 → 生成 → 编辑 → 复制 → 微信手动粘贴**。网页和服务在电脑，LLM 使用服务端配置的 DeepSeek API；不是本地运行大模型权重。Android Studio 演示使用内置能力，无需额外插件、Docker 或模拟器。

## 启动网页与真实 LLM

需要 Node.js 22+，在仓库根目录执行：

```sh
npm ci
npm start
```

打开 [本地网页](http://127.0.0.1:4173)。新克隆没有密钥，仅显示本地示例；把 `.env.example` 复制为 `.env`，只在服务端填写以下配置，再重启服务：

```dotenv
LLM_API_KEY=自己的DeepSeek密钥
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-flash
TYPESAFE_API_KEY=
BIND_HOST=127.0.0.1
PORT=4173
```

Jev 可选，留空不影响 LLM 分析；将来配好 `TYPESAFE_API_KEY` 才增加分类。密钥不要放进网页、APK 或 GitHub。当前开发电脑已配置真实 LLM，新克隆需自行配置。

图片要求视觉模型；小视频另需 [MEDIA.md](../MEDIA.md) 中的 Python 与语音环境。文字和图片演示不必安装本地语音模型。本机已配置的视频依赖可复用，这次不重复下载。

## USB 真机连接

手机启用开发者选项与 USB 调试，用数据线连接电脑，在手机上确认调试授权。电脑需要 Android SDK Platform-Tools；原开发电脑已有工作目录 SDK，但工具链不随仓库分发。以下假设 `adb` 已在 PATH，否则使用自己 SDK 中 `platform-tools/adb.exe` 的完整路径。

```sh
adb devices
adb reverse tcp:4173 tcp:4173
adb install -r downloads/xingyu-android-debug.apk
```

设备状态须为 `device`。若是 `unauthorized`，先在手机确认授权；若为空，检查数据线、USB 模式和厂商驱动。多台设备时每条命令都加 `-s 设备序列号`。

打开星语，在设置里点 **USB 本地调试**，确认地址为 `http://127.0.0.1:4173`，保存并打开。无需微信 AppID 即可分析、编辑和复制。转发将手机回环端口连接到电脑，USB 与电脑服务需保持运行；断线后可能要重新执行 `adb reverse`。

只有 Debug 包允许这个固定的 HTTP 回环地址；Release 仍要求 HTTPS。没有转发时，直接把电脑的 `127.0.0.1` 填给手机无效。结束演示可移除本次转发：

```sh
adb reverse --remove tcp:4173
```

## Android Studio 里展示测试机

已安装 Studio 时打开 `clients/android` 工程，选择 USB 真机运行 Debug；也可先安装 APK，再从 **View → Tool Windows → Device Manager / Running Devices** 打开设备镜像。在 **Settings → Tools → Device Mirroring** 调整启动方式。这是内置能力，不需要投屏或 AI 插件。[官方真机与镜像说明](https://developer.android.com/studio/run/device)

本机常见路径尚未发现 Studio，不能把“已有 SDK / 已构建 APK”当成“Studio 已安装”。未装 Studio 也能先用 `adb` 在手机演示；以后安装时复用已有 SDK，不必同时下载模拟器镜像。

自行构建时，`JAVA_HOME` 必须指向 JDK 根目录，不能指向它的 `bin` 子目录。若本机变量填错，可只在当前 PowerShell 修正；将下方示例换成自己的实际 JDK 目录，不必改动全局设置：

```powershell
$env:JAVA_HOME = 'C:\你的JDK安装目录'
& "$env:JAVA_HOME\bin\java.exe" -version
```

优先真机，闲置时关闭镜像，只打开当前工程。演示时可用 **File → Power Save Mode** 暂停部分后台检查，提交前仍运行项目测试；不把统一堆上限强加给所有电脑。[官方低内存配置](https://developer.android.com/studio/intro/studio-config#low_memory)

工程目前设置 Gradle 为 1 个 worker、关闭并行、堆上限 1 GiB；这不是进程总内存上限。本次 Node 空闲单次快照：Working Set 约 51.4 MiB、Private Memory 约 26.8 MiB；不含 Chrome、Studio、Gradle、模型服务或语音进程，也不是峰值，手机与演示负载仍待实测。

## 三分钟演示

1. 粘贴“今天降温了，出门记得加件衣服，忙也要好好吃饭”，选妈妈，生成并确认来源为 LLM。
2. 核对摘要、可能的理解，编辑成符合自己情况的表达，复制后到手机微信粘贴，用户决定是否发送。
3. 回星语继续改稿，刷新检查当前标签页草稿；附件不缓存，恢复后须重选。“清空草稿”删除本次暂存，关闭标签页或系统清理后的恢复不作保证。
4. 有视觉能力时选择不含私人信息的测试图片，核对识别依据后回复。视频先检查语音环境，不用文件名或模板冒充观看结果。

没有有效微信 AppID，不能演示 SDK 直接选人；系统分享不保证微信接受。当前也没有从微信分享进星语的接收入口，先复制文字或保存媒体后选文件。
