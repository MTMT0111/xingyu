# 后台速度、评论和相关视频验收 · 2026-10-21

本轮使用真实已登录微信会话、wx_channel 本机连接器与官方 DeepSeek Flash。测试资料没有使用合成视频替代；接口自动测试使用夹具，和真实验收分开统计。未发送微信消息。

## 改动

- 本机密钥设置接口验证后原子替换 `.env` 的三个模型配置项，保留其余环境；固定官方 HTTPS 地址。密钥不回显、不写入客户端设置或公开包；公网服务禁止此接口。已用开发机现有密钥完成一次真实验证和保存。
- 请求提供只含阶段、耗时的进度；客户端收起后继续处理，可随时唤醒查看。不会把微信自动播放的所有推荐都提交给模型。
- 下载、语音处理与评论读取并行；已完成的视频资料在内存复用十分钟、最多八条、每条不超过 1 MiB。对象和回复不进入资料缓存；「刷新依据」跳过缓存。重启服务后缓存消失。
- 主评论最多八页，热门六个分支各两页，总计最多二百条，二十秒评论预算；去重、保留上下级关系、按返回点赞数排列。停止标志优先于仍存在的分页游标，避免重复翻页。只显示实际取得的数量。
- 深度分析分成具体主张、实际来源编号、评论不同意见、信息缺口；最终回复仍短而自然。点赞不转换成可信度百分比。
- 生成后自动检索两组具体话题，最多显示六条真实候选。可继续分析，也可复制有效原链接；无原链接时只复制作者和标题。候选未分析，不混进原视频证据。
