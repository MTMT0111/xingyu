# 言外：免费临时手机试用

更新日期：2026-10-14。

安卓本地演示优先使用 [USB 本地部署指南](本地部署与安卓演示.md)：电脑启动服务，执行 `adb reverse tcp:4173 tcp:4173`，Debug 客户端选“USB 本地调试”。不需要公网隧道、微信 AppID 或额外插件。2026-10-14 已在 Android 9 / MEmu / WebView 68 完成当前轻量插件版和真实 DeepSeek 闭环；实体手机与真实微信仍未验证。下文临时 HTTPS 用于独立手机浏览器 / 微信网页访问。

Android 客户端可接收系统分享的单段文字、单张 JPG/PNG/WebP 或单个 MP4/WebM/MOV，也支持应用的选中文字菜单（`ACTION_PROCESS_TEXT`）。还提供原生“粘贴”、启动器静态快捷方式“分析剪贴板”、快捷设置磁贴“言外”、`?host=android` 紧凑页、“复制返回”和原生“发送”。外部分享、显式粘贴或磁贴入口一次确认后自动生成；启动器快捷方式只打开 App，仍需点“粘贴”。普通页面输入仍由用户点生成。入口是否在微信出现依微信版本与 ROM 而定。通用系统分享不需要微信 AppID；直接 SDK 选联系人仍需要合格主体与匹配包名/签名的 AppID，当前个人主体不能申请。

普通系统分享、选中文字和回复键盘只申请联网权限，不申请存储、联系人或传统悬浮窗权限，也不监听剪贴板。可选微信悬浮球是单独启用的实验入口：阅读说明并手动开启 Android 无障碍服务后，它只在微信前台显示，只有用户点击才读取当前页面暴露的可见文字；进入言外后仍需再次确认才上传。它不能读取视频画面、声音、隐藏记录或微信内部搜索数据，也不会代发。

临时公网 HTTPS 由下方启动器按需创建。地址会随进程退出而失效，也不能替代小程序发布所需的固定域名与后台登记。

## 你在这台电脑上怎么启动

1. 安装 Node.js 22 或更新版本，在仓库根目录执行 `npm ci`。新克隆不含模型密钥；需要真实生成时，先将 `.env.example` 复制为 `.env` 并按 [README](../README.md) 配置自己的 LLM。Jev 是可选分类器，尚未真实验收，不阻止 LLM 独立运行。
2. 从仓库根目录的 Windows PowerShell 中运行：

   ```powershell
   & '.\scripts\start-free-trial.ps1'
   ```

   如果系统执行策略禁止运行，先查看脚本内容，再按你的 Windows 管理策略处理；此启动器不会修改执行策略。

3. 成功后终端显示临时 `https://…trycloudflare.com` 地址。手机浏览器打开它，用户名填 `trial`。随机口令保存在电脑的 `work/free-trial/access.json` 的 `password` 字段；该文件限制当前 Windows 用户访问，不放进源码交付包。
4. 在安卓客户端“配置”里也可以填这个 HTTPS 地址。当前个人主体不能创建所需微信移动应用，客户端内的 SDK“去微信选人”尚不可用；通用系统分享仍可使用。先试生成、编辑、原生“发送”或复制回复；真实 AI 仍需有效模型配置。
5. 结束试用时运行：

   ```powershell
   & '.\scripts\start-free-trial.ps1' -Stop
   ```

脚本只停止自己记录且启动时间匹配的进程，不停止本地 4173 页面。`-Stop` 会删除当前试用口令文件；下次启动生成新口令和新域名。

## 启动器实际做什么

校验 Cloudflare 客户端 → 取得并严格验证临时域名 → 生成 192 位随机口令 → 从项目本机 `.env` 读取服务设置 → 以精确 `PUBLIC_ORIGIN` 和 Basic 登录启动 4174 → 检查公网未登录 401、登录 200、私有路径 404。

启动器不打印模型密钥或试用口令，不调用模型；失败会清理本次启动的两个进程。隧道日志及检查报告在 `work/free-trial/`，不要将 `access.json` 或 `.env` 上传或一起打包。

## 免费范围与尚未完成项

Android 安装后可这样配置轻量入口：

- 长按启动器中的言外图标，点“分析剪贴板”；它只打开 App，仍需点顶部“粘贴”，支持的启动器可将它拖到桌面。
- 展开系统快捷设置并进入编辑页，将“言外”磁贴加入常用区。之后复制文字并点磁贴即可进入前台确认流程；磁贴使用一次性令牌，不能由普通外部 action 冒充。
- 已打开言外时，可直接点原生工具栏“粘贴”。

三个入口都只在用户主动触发后读取一次剪贴板首项文本。回复生成后可点原生“发送”打开系统分享面板；是否显示微信及能进入哪些微信场景由设备上的微信版本与系统策略决定。

Cloudflare Quick Tunnel 无需账号或自购域名，适合开发试用；无可用性保证、电脑休眠/关机或隧道退出后即失效，重启会换域名。不同手机网络能否访问需要实际验证，不适合填作长期微信审核域名。依据：[Cloudflare 官方说明](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。

这里免费的是临时 HTTPS 通道。DeepSeek/Jev 的模型调用是否收费取决于账号额度；开通通道不会赠送模型额度。Jev 配置、Kiro 状态、微信移动应用 AppID、实体安卓微信、iPhone 编译及真机验收的未完成事项以项目 [README](../README.md) 为准。
