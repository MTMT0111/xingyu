把这个链接发给朋友，朋友能直接用吗？

可以随时打开本页、编辑复制实测回复和使用文字示例；这些不调用实时 AI。要分析自己的视频和微信内容，需要下载本机包、配置自己的模型密钥，视频号功能还需要本人登录的微信会话。公开页不会借用作者的微信或 API 密钥。

微信卡片能直接拖入吗？

微信私有视频号卡片不能直接当作文件拖入。请先在微信点开原卡片一次，再点“从微信接入”或按 Ctrl+Alt+V，核对标题、作者和时间后选择原视频，不用看完。连接器使用真实视频标识，主流程不依赖 OCR；视频号会话需保持连接。视频文件和可复制的原分享链接仍可拖入，视频文件本身不包含评论身份。

多长的视频都能分析吗？

已移除 60 秒限制，按每 3 分钟一段处理完整音轨并取 6 帧。真实验证通过 6 分 16 秒的视频。当前文件上限 512 MiB / 4K，处理时限 90 分钟，另有证据容量限制；不能保证任意时长、编码和权限的视频都成功，超限会报错，不截断后冒充完整分析。

微信连接器会改变什么？

可选连接器基于开源 wx_channel，需要本人确认安装 SunnyRoot 根证书并启用微信进程代理，仅使用本机登录会话。微信升级、权限或会话过期可能影响可用性。文件分析不需要安装它；安装步骤和退出说明随包提供。
