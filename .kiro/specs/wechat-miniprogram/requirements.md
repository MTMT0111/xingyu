# 微信小程序需求

本规格由 **Codex** 根据用户要求与当前实现编写，待 Kiro 实际审阅。它不是 Kiro 已完成开发的证据。

1. 小程序必须使用原生 WXML/WXSS/JavaScript，不把现有网页塞进 `web-view`，不引入第三方 UI 插件。
2. 用户可主动粘贴最多 6000 字文字/公众号链接，从微信会话或相册选择单张 JPG/PNG/WebP 图片（≤4 MB）或单个 MP4/WebM/MOV 视频（≤20 MB、≤60 秒）。没有用户点击不得读取剪贴板或文件。
3. 小程序复用现有 `/api/config`、`/api/reply`；模型密钥只在服务端。开发者工具可用本机地址，真机/正式版只接受已登记的 HTTPS 根域名。
4. 回复对象和语气必须传到服务端；结果展示摘要、可能理解、继续聊的方向、可选识别依据和可编辑回复。复制后由用户回原聊天粘贴、确认发送。
5. 不读取好友、通讯录或聊天记录，不自动接收消息，不预选联系人，不声称回复已送达。连接、生成或复制失败时保留当前输入和附件。
6. 发布前必须配置小程序 AppID、`request` 合法域名、《用户隐私保护指引》，并在 Android/iPhone 微信分别验收。
