# 微信小程序设计

入口为一个原生单页工具：文字或媒体 → 生成 → 编辑回复 → 复制回微信。对象由内容自动判断，回复优先出现，摘要与可能理解默认收起；连接设置留在次级面板。界面使用米白、深绿和少量暖黄，不放星球或无功能插画，所有主要触控目标保持可点尺寸。

`pages/index/index.js` 只做微信运行时交互；`utils.js` 集中处理服务根地址、Basic 邀请口令、Unicode、媒体和响应边界，Node 测试直接复用。媒体在选择后本地预览，点击生成才由文件系统读取为 Base64 并调用现有 JSON API。此方式复用后端且不增加依赖；若以后提高 20 MB 限制，再改流式上传。

开发配置使用 `touristappid` 和本机地址。正式运行需要替换 AppID、打开域名校验、部署 HTTPS 后端并登记 `request` 域名。隐私接口使用微信官方统一授权流程；后台未声明隐私用途时不得发布。
