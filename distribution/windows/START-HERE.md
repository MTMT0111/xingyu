# 知意 · Windows 本机体验

公开展示页：https://mtmt0111.github.io/xingyu/showcase.html

## 第一次使用

1. **完整解压**到自己的目录，不要在压缩包内运行。安装 [Node.js 22+](https://nodejs.org/)；视频分析另需 [Python 3.11 或 3.12](https://www.python.org/downloads/windows/)，安装时勾选 Add to PATH。
2. 双击 `setup.cmd`。输入自己的 DeepSeek API 密钥（输入不会显示）；按提示安装本地视频依赖与多语言语音模型，首次需要联网下载数百 MB。密钥仅保存在自己的 `.env`。没有密钥也能体验文字示例，但那不是 AI。
3. 双击 `start-local.cmd`。服务在本机后台运行，打开悬浮球。**Ctrl+Alt+R** 唤起/收起；拖入一个视频文件或分享链接，填回复对象，点击生成。结果可编辑，展开“查看依据”核对分段与评论；复制后回到微信自行粘贴发送。

密钥也可以稍后在悬浮窗「服务 → DeepSeek 密钥 · 配置 / 更换」填写。验证成功才保存，立即生效；关闭输入框不改变已有配置。使用官方 `deepseek-flash`，每次保存有一次很小的验证调用。服务仅接受本机设置，公开展示页没有密钥输入入口。

分析会显示当前阶段和已用时间，收起窗口后仍继续。相同视频资料在本进程复用十分钟，换一句通常只需重新生成回复；需要最新评论时点「刷新依据」。已读取的转写和评论保留在有限的本机内存缓存中；结束服务即清除。生成时这些资料仍会提交到你配置的模型服务。评论最多 200 条、20 秒预算，实际返回范围在依据页说明。生成后自动出现最多六条真实相关视频候选，候选需要单独分析，不能当成原视频已验证事实。
4. 如果只体验文字：在此目录运行 `powershell -ExecutionPolicy Bypass -File setup.ps1 -TextOnly`，可跳过 Python 和语音模型。

文件分析无需微信连接器。图像/视频需要支持视觉输入的模型；默认配置按本次实测的 DeepSeek Flash 设置。其他供应商可编辑 `.env`。语音在本机转写，选中内容、画面样本、转写及关系备注会在点击生成后发给配置的模型服务。

## 可选：直接读取微信视频号与评论

1. 下载同一 Release 的 `zhiyi-wechat-connector.zip`，把其中 `connector` 文件夹解压到本包内。
2. 双击 `enable-wechat.cmd`。脚本说明证书与代理变更，输入 `ENABLE` 才会继续；需要 Windows 管理员及证书确认。这是第三方开源连接器，不是微信官方插件。
3. 登录**自己的电脑版微信**，打开“视频号”首页并保持打开。目标视频不必播放。连接器依赖该会话，微信升级、登录过期或内容权限可能影响读取。
4. 双击 `stop-local.cmd`，再双击 `start-local.cmd` 让服务读取连接器配置。悬浮窗中粘贴/拖入微信分享链接，或使用视频号搜索。视频文件可直接拖入；文件本身没有评论身份，只有视频号原链接/搜索结果能关联评论。

**微信视频号卡片不能当作视频文件拖入。** 请在微信点开卡片一次，再点“从微信接入”或按 **Ctrl+Alt+V**，核对标题、作者和时间后选择原视频。不用看完；连接器直接保留微信返回的标识，不经过 OCR。需要视频号窗口保持打开；推荐视频也会出现在列表，不会自动选择。连接器重启后记录清空，请重新打开卡片。也可粘贴原始链接；框选卡片查找作为右键备用入口，必须核对结果。

生成后，“查看依据”按概要、转写和评论分栏；“找相关视频”搜索实际相关候选，选中后可分析。候选尚未阅读，不算原视频证据；没有分享链接时只复制作者和标题供微信搜索，不冒充可直接转发的链接。公众号链接直接读取公开正文，不会自动读取文章中的嵌入视频。

## 使用边界与停止

- 公开网页是稳定展示与文字示例，不能连接访客的微信，也不提供免费的共享模型密钥。完整功能使用本机程序和自己的会话。
- 视频文件上限 **512 MiB / 4K**；不再限制 60 秒，每 3 分钟处理一段完整音轨并抽取 6 帧。存在 90 分钟处理时限和证据容量上限；受损编码、受限内容会报错，不能保证任意时长任意视频成功。
- 评论是本次接口可获得的样本，按实际点赞数排序。点赞多不等于正确，也不等于已读全部评论；没有捏造可信度百分比。
- 对象是自己提供的称呼/关系备注，不是枚举微信好友。回复不会自动发送；仅保存明确输入的关系备注，存在 `%LOCALAPPDATA%/Zhiyi/recipients.json`。
- 停止服务：`stop-local.cmd`。退出助手：悬浮球右键 → 退出。连接器可通过任务管理器结束 `wx_channel-local.exe`；退出后检查系统代理状态。仅不再需要该证书且确认无其他工具依赖时，在 Windows 证书管理器中按 SunnyRoot 核对并移除；不要删除其他根证书。
- 升级前退出旧助手与本包服务；保留自己的 `.env`、`.venv`、`models`。不要把 `.env`、连接器配置、日志或微信会话打包转发。

## 遇到问题

- AI 回复不完整：点击「查看已读资料」，进入「原文与转写」「分段摘要」「评论样本」；需要留存可点「导出这次资料」。完整视频资料在服务进程内缓存 10 分钟，重试可复用；关闭服务后缓存不保留，未完成的画面分析需要重读。
- 密钥确认：服务 → DeepSeek 密钥 → 填入新密钥后点「验证并保存新密钥」；已有密钥则直接点「验证已保存密钥」。绿色成功提示包含模型和时间。仅显示「已配置」不代表本次验证通过；网络、认证、余额和保存失败会分别提示。

- 端口 4173 被占：先退出之前运行的本地服务，启动器不会强占或结束其他项目。
- 视频功能未就绪：确认 setup 成功完成，`.env` 的 Python 与模型路径仍有效。移动安装目录后重跑 setup 更新路径。
- 本地服务启动失败：查看 `runtime/server-error.log`。模型无余额、无视觉权限或连接器离线会明确报错，不切换成模拟结果。
- 下载被 Windows 提醒：本试用 EXE 未做商业代码签名。先核对 Release 的 SHA256SUMS.txt，再决定是否运行；不要关闭系统防护。

本包按白名单收录运行文件，不含作者的 API 密钥、微信令牌、聊天数据或模型权重。已验证本机真实链路和干净目录启动；尚未在第二台全新 Windows/实体 Android 手机上完成验收。
