在自己的微信旁使用

需要实时分析时，使用完整的 Windows 本机包。悬浮客户端免安装；后台需要单独配置一次。

  1. 完整解压 Windows 本机包，先读 START-HERE.md。
  2. 准备 Node.js 22+，运行 setup.cmd；视频分析另需 Python 3.11 / 3.12 与语音模型。
  3. 运行 start-local.cmd，在悬浮窗「服务」中验证并保存自己的密钥。微信视频号读取按指南启用可选连接器。

独立的免安装展示包不含后台程序。真实分析使用自己的模型密钥和已登录微信会话，不提供共享密钥；回复由你确认发送。
