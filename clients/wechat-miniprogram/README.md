# 言外 · 微信小程序

这是原生微信小程序客户端，不使用 `web-view`、第三方 UI 框架或额外插件。它复用仓库现有 `/api/config` 和 `/api/reply`：用户主动粘贴文字/公众号链接、从聊天素材菜单把视频交给小程序，或从微信聊天/相册选择图片和 60 秒内视频；点击分析后由服务端处理，结果可编辑并复制回聊天。

真机首次打开不会再连接 `127.0.0.1`：没有配置 HTTPS 服务时直接进入离线文字体验，仍可生成、编辑、换一句并复制；图片、视频和真实 AI 会明确要求先连接服务。连接设置保持折叠，不占据主流程。

发布后可在微信右上角菜单收藏，或添加到“我的小程序”；收藏项、转发卡片和朋友圈分享都回到同一个首页。它随当前微信账号使用，不要求再注册产品账号。小程序声明了 `video/*` 聊天素材入口：在微信聊天中打开视频的菜单，选择“用言外分析”，小程序会收到该视频并预填附件。此能力需通过微信审核后才会在聊天菜单出现；开发阶段可在开发者工具用自定义场景 `1173` 验证。

## 已实现

- `wx.getClipboardData`：只在用户点击“粘贴文字”后读取。
- `wx.chooseMessageFile`：从微信会话选择单张图片或单个视频。
- `supportedMaterials` / `scene=1173`：从微信聊天视频的“用小程序打开”入口直接接收素材；打开后需要用户点击“理解并生成回复”才会上传分析。
- `wx.chooseMedia`：从相册选择或拍摄图片/视频。
- 图片 4 MB、视频 20 MB / 60 秒、文字 6000 字的客户端校验；服务端仍会再次校验真实内容。
- AI 自动判断聊天语境并生成自然、礼貌的回复，不要求用户先选对象或语气；未连接服务时使用明确标注的本地规则和人工文案。
- 内容摘要、可能理解、识别依据、可编辑回复和剪贴板复制。
- 微信收藏、好友转发和朋友圈入口统一回到首页，适合把卡片发给文件传输助手后长期使用。
- 服务地址和邀请试用口令设置；DeepSeek、Jev 等模型密钥始终只留在服务端。

素材入口只交付用户主动打开的单个视频，不会读取聊天记录、发送者身份、联系人列表或普通聊天文字，也不会代替用户发送。视频号卡片或外部视频链接不一定是 `video/*` 文件，当前只对微信实际交付的视频文件做逐帧和语音分析；未匹配到入口时仍可从“选聊天文件”或相册选择视频。公众号文章、普通文字仍需复制到小程序。生成后点复制并返回聊天，由用户确认发送。

## 开发者工具本机运行

1. 在仓库根目录运行 `npm start`，确认 `http://127.0.0.1:4173/api/config` 可访问。
2. 安装并登录[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。当前电脑已安装腾讯签名的稳定版 `2.02.2609231`，位置为 `D:\CodexTools\WeixinDevTools`。
3. 导入目录 `clients/wechat-miniprogram`。仓库已配置本项目的小程序 AppID `wx44641c021b958fdd`；若复制为其他小程序，再替换 `project.config.json` 中的 AppID。
4. 当前 `project.config.json` 为本机联调关闭了合法域名检查，因此模拟器可连接 `http://127.0.0.1:4173`。发布前必须恢复合法域名检查，并使用已登记的 HTTPS 域名。
5. 开发者账号可在微信的小程序助手/版本管理中打开已上传的 `0.8.0` 开发版本，也可使用开发者工具直接推送预览。正式发布后可收藏或添加到“我的小程序”，并把小程序卡片转发到常用聊天或文件传输助手作为固定入口。

2026-10-17 本机实测：微信开发者工具通过 `auto-preview` 推送体验预览，并成功上传 `0.8.0` 开发版本（41,838 字节，新增聊天视频直达分析入口）。仓库 63 项自动测试全部通过，其中小程序专项 14 项。本地合成视频完成真实 Whisper 解码和 HTTP 流程；另一次真实在线 LLM 请求返回了视频摘要、可能意图和礼貌回复（HTTP 200，`decision_source=llm`、`generation_source=llm`）。当前运行配置没有启用 Jev 路由。此轮尚未连接实体手机，也未完成场景 `1173` 的开发者工具模拟、Android 微信真机菜单验证或平台审核；真实 AI 真机联网仍需 HTTPS 地址和后台合法域名。合成样片语音转写出现少量同音字错误，发送前应检查识别依据。

## 真机和发布前配置

移动应用 AppID 与小程序 AppID 是两套登记。个人主体不能创建移动应用，不等于不能注册小程序；实际可用类目和审核要求以小程序后台为准。

1. 在[微信公众平台](https://mp.weixin.qq.com/)登录当前小程序，确认“开发管理 / 开发设置”中的 AppID 与 `project.config.json` 一致。
2. 把现有 Node 服务部署到固定 HTTPS 根域名。服务器 `.env` 设置 `PUBLIC_ORIGIN`、`TRIAL_PASSWORD` 和 LLM 配置；不要把模型密钥或 AppSecret 写入小程序。
3. 在小程序后台“开发设置 / 服务器域名”把该 HTTPS 根域名加入 `request` 合法域名。真机不能使用 IP、`localhost` 或电脑的 `127.0.0.1`。
4. 在小程序后台填写《用户隐私保护指引》，如实声明剪贴板、会话文件、相册/相机以及把用户主动提交的文字/图片/视频发送到自有服务和模型提供商。项目已启用 `__usePrivacyCheck__`，未完成后台声明时相关接口会被微信拦截。
5. 小程序“设置”中填写同一 HTTPS 根地址和邀请试用口令。当前口令保存在该小程序的本地存储，便于测试；正式公开前应改为 `wx.login` 对应的服务端会话和用户级额度。
6. 在开发者工具打开合法域名检查，用自定义编译场景 `1173` 和 `forwardMaterials` 测试视频素材入口；再预览到 Android / iPhone 微信，逐项验证普通视频、拒绝隐私授权、断网、复制与回原聊天。聊天素材菜单需以体验版/正式版及平台审核结果在真机确认。
7. 完成名称、头像、类目、隐私指引和体验成员配置后，在开发者工具上传版本，再由小程序后台提交审核。
