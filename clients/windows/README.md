# 知意 Windows 微信悬浮助手

这是电脑版微信旁边的轻量客户端。它是一个约 37 KB 的原生 Windows 可执行文件，不使用 Electron，也不安装浏览器插件。

## 直接体验

1. 在仓库根目录运行 `npm start`，确认本机服务是 `http://127.0.0.1:4173`。
2. 双击 [`downloads/zhiyi-windows.exe`](../../downloads/zhiyi-windows.exe)。
3. 在电脑版微信打开一个聊天、公众号文章或视频画面。
4. 点击贴在微信右侧的绿色“知”悬浮球。
5. 核对“当前对象”和读取内容，按需补充一句，然后生成、修改并点“复制并回微信”。
6. 在微信输入框粘贴，由用户确认发送。右键悬浮球可以退出。

客户端会跟随微信窗口，但不会后台持续采集内容。每次只有用户点击悬浮球或“读取当前微信”时，才读取这一次微信向 Windows 辅助功能公开的可见文字并截取聊天区域；密码字段会跳过。截图和所选媒体不落盘，点击生成后才传给本机服务。

## 能力边界

- **聊天与当前对象：**优先识别微信当前选中的会话或顶部标题；识别不准时可在输入框直接改。微信桌面端没有向普通应用开放好友列表和代发接口，所以不会伪造“选好友”，也不会自动发送。
- **公众号文章：**读取当前文章窗口向 Windows 辅助功能暴露的文字，并附当前画面。若微信内网页没有暴露完整正文，只能分析可见部分；可滚动后再次读取，或复制正文。
- **微信短视频：**微信 4.0 自绘的视频卡片不会把原视频文件交给 Windows 辅助功能。点悬浮球可分析聊天区域里的封面和可见评论，但不能读取视频语音或完整画面。完整分析请在微信长按视频转发到已声明 `video/*` 素材入口的小程序；桌面端也可把实际视频文件拖到侧栏，或先保存再点“选择聊天视频文件”。限制为 20 MiB、60 秒。
- **模型与密钥：**客户端只调用本机 `/api/reply`，DeepSeek 密钥仍保留在服务端。服务地址默认只接受本机 HTTP；远程地址必须使用 HTTPS。

## 构建与自检

Windows 10/11 自带的 .NET Framework 即可运行，无额外运行库。重新构建：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\clients\windows\build.ps1
```

脚本使用系统 C# 编译器生成 `downloads/zhiyi-windows.exe`，执行文字去重和当前聊天识别自检，并生成 `screenshots/windows-companion.png`。源码只依赖 WinForms、Windows UI Automation 和现有服务接口。
